Sobre a NEY JR STORE

A NEY JR STORE é uma loja digital de jogos criada como projeto acadêmico. O catálogo, os cadastros, o carrinho e os pedidos funcionam com um banco de dados real hospedado no Supabase (PostgreSQL), com autenticação de usuários e painel administrativo completo.
